# AI Test Case Generator

An AI-powered software testing tool that generates structured QA test cases from natural-language software requirements using the Gemini API.

## Overview

The AI Test Case Generator helps QA testers and developers quickly create software test cases from a given requirement.

Users can enter a software requirement, select the type of testing they want, choose the number of test cases, and generate structured test cases using AI.

The application supports different testing scenarios while keeping generated test cases structured, realistic, and independently understandable.

## Features

- Generate test cases from natural-language software requirements
- Functional Testing
- Negative Testing
- Edge Case Testing
- Regression Testing
- All Types option for mixed test coverage
- AI decides option for automatic test case count
- Exact requested test case count with validation and retry
- Retry handling for temporary Gemini service errors
- Structured test case output
- Test case priority classification
- Expandable detailed test cases
- Copy test case table
- Export test cases as CSV
- Test execution status tracking
- API key protection using environment variables

## Test Case Information

Each generated test case includes:

- Test Case ID
- Objective
- Scenario
- Test Type
- Preconditions
- Test Data
- Test Steps
- Expected Result
- Postconditions
- Priority
- Status

Actual Result and execution Status are handled by the application rather than generated by the AI.

## How It Works

1. The user enters a software requirement.
2. The user selects a testing type.
3. The user selects the required number of test cases or allows AI to decide.
4. The frontend sends the request to the Node.js backend.
5. The backend sends the requirement and generation instructions to Gemini.
6. Gemini returns structured JSON according to the defined schema.
7. The backend validates the generated response.
8. The frontend displays the generated test cases.
9. Users can copy the table or export the test cases as CSV.
